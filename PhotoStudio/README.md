Photo Studio 7.1 — Smart Crop batch / Sort 1–250

Updates:
- Smart Crop: choose several photos in one batch, use one normalized crop rectangle for all; the free-scale slider changes the actual crop dimensions.
- Sort: each folder can contain 1–250 images; slider and precise numeric input remain synchronized.
- Batch queues render visible items only; uploads run with a maximum of four workers.
- Original media files remain unchanged. Jobs are saved into unique timestamped result folders.

IMPORTANT: The installation page is HTML and does not itself become a native application. It downloads a platform-specific installer, which creates an application launcher. On macOS and Windows the current app runs a local Python service with an HTML interface opened in a standalone browser window when available. A fully native installer-to-app workflow requires a separate desktop wrapper/build for each platform.

Not yet tested: physical Windows or macOS, Gatekeeper/SmartScreen, Facy authorized production service, batch with thousands of high-resolution photos on a real machine. First installation downloads dependencies.
